SR4710 Drive Offload

A personal recording archive tool. It uploads completed TikTok recordings from the operator's server to the Google Drive account that the operator authorizes.

The uploader verifies each archive using file size and a checksum. A background service retries interrupted uploads. Optional local cleanup requires a verified archive copy.

Google authorization is requested with the limited drive.file scope. The app uses access to the archive files and folders it creates or that the user explicitly selects.
